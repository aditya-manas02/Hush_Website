Installation Override Protocol (Chrome / Edge / Brave)

Due to advanced security protocols, this payload cannot be distributed via standard web stores. Follow the manual override instructions below.

  • Extract the Payload: Unzip the downloaded Hush_Extension_Chrome.zip file to a folder on your computer.
  • Access Extensions Dashboard: Open your browser and navigate to chrome://extensions/ in the URL bar.
  • Enable Developer Override: Toggle the Developer mode switch in the top right corner of the page to the ON position.
  • Load the Package: Click the Load unpacked button in the top left corner.
  • Select Directory: Choose the folder you extracted in Step 1. The ghost protocol will instantly initialize.

Installation Override Protocol (Firefox)

  • Extract the Payload: Unzip the downloaded Hush_Extension_Firefox.zip file to a folder.
  • Access Debug Dashboard: Open Firefox and navigate to about:debugging#/runtime/this-firefox in the URL bar.
  • Load Temporary Add-on: Click the Load Temporary Add-on... button.
  • Select Manifest: Open the extracted folder and select the manifest.json file. The protocol is now active.
